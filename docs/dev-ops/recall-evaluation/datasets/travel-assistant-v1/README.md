# 旅行助手召回评测集 v1

这是一套可直接导入“召回评测实验室”的中文合成数据，用于测试：

- RAG 文档召回；
- 长期记忆与用户偏好召回；
- RAG + Memory 混合召回；
- 相似城市、相似政策、同主题不同约束造成的干扰；
- 可选 Context Planner 对候选集合的二次筛选。

## 规模

- 26 条语料：12 条 RAG 文档、8 条长期记忆、6 条用户偏好；
- 40 个带标准答案的问题；
- 相关性等级使用 `grade=1..3`；
- RAG 使用 `PARENT_DOCUMENT`，记忆与偏好使用 `EXACT_SOURCE`。

## 导入顺序

1. 在评测实验室中新建数据集，例如 `旅行助手召回基线 v1`。
2. 在“语料库”中以 JSONL 格式导入 `corpus.jsonl`。
3. 确认语料大部分进入 `READY` 状态。
4. 在“问题与标签”中以 JSONL 格式导入 `cases.jsonl`。
5. 先运行 `VECTOR / TopK=10 / minScore=0.20 / Planner 关闭` 作为基线。
6. 再运行 `HYBRID` 或开启 Context Planner，与基线进行 A/B 对比。

所有内容均为合成数据，不代表真实签证、保险、交通或商业政策。
