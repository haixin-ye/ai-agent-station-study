# 旅行助手召回测试集 v1（旧版）

这套数据是早期的旅行场景样例，使用字母数字混合 ID。当前“召回批量测试”页面已经统一要求 5–12 位数字 ID，因此这套数据不再适合直接导入。

请改用：

`docs/dev-ops/recall-evaluation/datasets/multi-scenario-recall-v1/`

新版数据包含：

- 60 条 RAG 数据；
- 60 条长期记忆；
- 60 条用户偏好；
- 150 条测试问题；
- 6 类场景与同主题干扰项；
- 从 `10001` 开始的纯数字自定义 ID。

本目录仅保留用于历史对照，不再维护，也不要导入到采用数字 ID 规则的数据集中。
